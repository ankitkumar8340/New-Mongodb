# New MongoDB

A practice repository for learning MongoDB and Mongoose. It contains examples of CRUD operations, aggregation pipelines, schema design, and database integration.

## Features

* CRUD Operations
* Aggregation Pipeline
* Schema Design
* Mongoose Models
* Query Examples
* Database Relationships
